# 信息安全制度

## 第十一条 账号口令
公司系统账号口令长度不得少于 12 位，且须包含大小写字母与数字，每 90 天更换一次。

## 第十二条 客户数据
禁止将客户数据导出至个人设备、私人网盘或个人邮箱。确因工作需要外发的，须经数据安全负责人书面批准并加密传输。

## 第十三条 密钥管理
API 密钥与数据库口令不得硬编码在代码或配置文件中，必须存放于公司密钥管理服务，并通过环境变量注入。

## 第十四条 事件上报
发现数据泄露或疑似安全事件，应在 1 小时内上报安全团队，并保留现场日志，不得自行删除相关记录。
